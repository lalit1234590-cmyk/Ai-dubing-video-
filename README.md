# Render-ready AI Video Dubbing

## Deploy
1. GitHub में इस folder की सभी files upload करें.
2. Render में New > Web Service चुनें.
3. GitHub repository connect करें.
4. Render Dockerfile को अपने-आप detect करेगा.
5. Deploy करें.

## Important
यह demo original audio को target AI voice से replace करता है। Background music/effects preservation और speaker-specific voice cloning इसमें अभी नहीं है।
लंबे videos के लिए free hosting resources पर्याप्त न हो सकते हैं।
